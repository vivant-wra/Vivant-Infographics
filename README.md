# Vivant infographics

Vivant is a powerful AI-driven engine designed to transform simple text prompts into professional infographic videos. Stop struggling with complex video editors—just describe your data, and let the AI handle the rest.

[📺 Watch Video Tutorial](https://www.youtube.com/watch?v=YOUR_VIDEO_ID) | [📂 View Sample Gallery](public/images/sample-gallery/)

---

## ✨ Key Features
- **Prompt-to-Video:** Generate full infographic scripts and visuals from a single sentence.
- **AI Providers:** Native support for any API providers (ultra-fast) and LM Studio (local/offline models).
- **Batch Generation:** Create multiple videos at once using batch prompts.
- **Deep Customization:** Adjust palettes, typography (including system fonts), and visual styles in real-time.
- **High-Res Export:** Support for MP4 and MOV (with Alpha channel) in 1080p, 2K, and 4K.

## 💻 System Requirements
- **OS:** Windows 10/11 (64-bit)
- **CPU:** Multi-core processor (Intel i5/AMD Ryzen 5 or better recommended)
- **RAM:** 16GB minimum
- **GPU:** Optional but recommended for hardware-accelerated rendering.
- **Node.js:** Not required (pre-bundled).

---

## 🛠 Recommendations
- **For Best Results:** Use **Groq, GPT etc** for instant generation or **LM Studio (Qwen3/Llama3)** for private, local workflows.
- **Customization:** Use the "Customize" tab to match the video to your brand identity before exporting.
- **Offline Use:** Once activated, you can generate and preview videos without an internet connection.
